# ابهام‌های API والکس و رفتار fail-closed کد

منابع این سند:

- نسخهٔ ذخیره‌شدهٔ مستند رسمی: [`wallex_official_api_reference_snapshot_2026-10-22.txt`](wallex_official_api_reference_snapshot_2026-10-22.txt)؛
- داده‌های واقعی عمومی ذخیره‌شده در `tests/fixtures/*_real*.json`؛
- اجرای `diagnose` و `paper` در ۲۰۲۶-۱۰-۲۲؛
- یادداشت‌های فنی [`WALLEX_CLIENT_NOTES.md`](WALLEX_CLIENT_NOTES.md) و [`CONTRACT.md`](CONTRACT.md).

> **وضعیت فعلی:** هیچ endpoint خصوصی تا امروز فراخوانی نشده است (هیچ کلیدی در دسترس نبوده)، و هیچ سفارش واقعی‌ای ثبت نشده است. ستون «حل با» نشان می‌دهد کدام مرحله **می‌تواند** هر مورد را روشن کند. خود `check-live` و `canary` هنوز هرگز اجرا نشده‌اند.

## راهنمای برچسب‌ها

| برچسب | معنی |
|---|---|
| **مستند** | در مستند رسمی آمده است (که خودش در چند جا غلط یا ناسازگار است) |
| **GET عمومی** | با درخواست‌های عمومی واقعی در ۲۰۲۶-۱۰-۲۲ تأیید شد |
| **check-live** | بررسی فقط‌خواندنی با کلید آن را روشن می‌کند (`live_schema_attestation.json`) |
| **canary** | یک سفارش واقعیِ پرنشدنی و لغوشده آن را روشن می‌کند (`live_canary.json`، فیلد `verified`) |
| **باز** | حتی پس از canary هم تأییدنشده می‌ماند |

### طبقه‌بندی پاسخ‌های HTTP به POST سفارش (ردیف ۲۳)

| پاسخ | تعبیر کد | نتیجه |
|---|---|---|
| 2xx و `success: true` و شکل معتبر | پذیرفته شد | OPEN، PARTIAL یا FILLED؛ پرشدن‌ها ثبت می‌شوند |
| 4xx به‌جز 401، 403، 408، 409 و 429 (شامل 422) | `RejectedError` | قطعی: سفارشی وجود ندارد (REJECTED) |
| 401، 403 | `AuthError` | **نتیجهٔ نامعلوم**، حل از روی شواهد |
| 429 | `RateLimitError` | **نتیجهٔ نامعلوم** |
| 408، 409 (والگیت 409 را «شناسهٔ تکراری» معرفی کرده) | `AmbiguousResponseError` | **نتیجهٔ نامعلوم** |
| 5xx، 1xx، 3xx، 600 به بالا | `ServerError` / `AmbiguousResponseError` | **نتیجهٔ نامعلوم** (ریدایرکت دنبال نمی‌شود) |
| timeout یا خطای شبکه، بدنهٔ ناخوانا یا خیلی بزرگ، `success` غیر از `true`، پاسخ ناهمخوان | `TransportError` / `SchemaError` | **نتیجهٔ نامعلوم** |

«نتیجهٔ نامعلوم» هرگز دوباره ارسال نمی‌شود. از روی شواهد صرافی حل، یا پس از بررسی رها و قرنطینه (و برای همیشه زیر نظر گرفته) می‌شود، یا (اگر تناقض باشد) ربات STOPPED می‌شود. جزئیات در [`ARCHITECTURE_FA.md`](ARCHITECTURE_FA.md) بخش ۶.

## آنچه canary روشن می‌کند و آنچه باز می‌ماند

فهرست کامل موارد تأییدنشده‌ای که `diagnose` در ۲۰۲۶-۱۰-۲۲ چاپ کرد (هنوز هیچ canary‌ای اجرا نشده است):

```text
account taker/maker fee (private endpoint: needs the key; conversion math above uses the ASSUMED 0.0035)
post_order_response_shape, client_id_echo, get_order_by_client_id, partial_fill_status,
terminal_active_flag, cancel_response, reject_http_codes, balance_value_includes_locked
```

| مورد | پس از یک canary موفق |
